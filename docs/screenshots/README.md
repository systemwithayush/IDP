# Screenshots

This folder contains screenshots of the IDP portal.

## How to add screenshots

1. Run the app: `npm run dev --workspace=@idp/web`
2. Open http://localhost:5173
3. Take screenshots and save them here with these names:

| File | Description |
|------|-------------|
| `login.png` | Login page with persona quick-select cards |
| `admin-dashboard.png` | Divya's admin dashboard (Fleet Overview tab) |
| `lead-dashboard.png` | Deepak's lead dashboard (Team Overview tab) |
| `dev-dashboard.png` | Ayush's developer dashboard (My Services tab) |

Screenshots are referenced in the root README.md.
